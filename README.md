# FoodVision Transfer Learning Studio

A reproducible training and evaluation workspace for Food-101 transfer learning experiments (ResNet18 and EfficientNet variants), with Windows double-click launchers for non-terminal users.

## Repository Layout

```text
.
+- checkpoints/                  # model checkpoints and run logs
+- data/                         # local datasets (gitignored)
+- docs/                         # project docs and course PDF
+- exports/                      # exported figures/tables
+- logs/                         # runtime and evaluation logs
+- model/                        # model implementations
+- model_specs/                  # JSON model specs
+- notebooks/                    # experiment notebooks
+- reports/                      # exported report HTML
+- scripts/
¦  +- app/                       # GUI app
¦  +- core/                      # shared runtime helpers
¦  +- entry/                     # CLI entry points
¦  +- maintenance/               # environment + launcher maintenance
¦  +- pipeline/                  # train/predict/data pipelines
+- workflow/                     # workflow utilities
+- Check Requirements.lnk        # launcher 1
+- Launch Training GUI.lnk       # launcher 2
+- requirements.txt
```

## Quick Start (Two `.lnk` Files)

For most Windows machines, initialization can be completed with these two root shortcuts:

1. Double-click `Check Requirements.lnk`
2. Wait until dependency check/install is done
3. Double-click `Launch Training GUI.lnk`

These launchers are generated by repo scripts and use project-relative startup scripts (no hardcoded absolute project path).

If shortcuts become stale, rebuild them from project root:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\maintenance\rebuild_gui_shortcuts.ps1
```

## Manual CLI Setup (Fallback)

```powershell
python -m pip install -r requirements.txt
python scripts/entry/data_retrieval.py
python scripts/entry/training.py --help
```

Example training run:

```powershell
python scripts/entry/training.py --model resnet18 --epochs 3 --batch-size 32 --num-workers 4 --image-size 224 --checkpoint-dir checkpoints\resnet18_cli
```
